# phishing_repo

Code and lightweight experiment outputs from the Google Drive project `html_token_analysis`.

## Included

- Main Jina v2 HTML pipeline source code
- Tag-ablation pipeline source code
- Controlled RAG/no-RAG and Top-K experiment source code
- Lightweight outputs: metrics, manifests, summaries, and evaluation CSVs

## Excluded

- `Dong_Phishing_Thesis` and university forms
- Raw HTML archives and source datasets
- Train/test chunks and input shards
- Embeddings, ChromaDB/vector indexes, and retrieval caches
- Model checkpoints, weights, tokenizer assets, and training state

Large generated artifacts should remain outside Git and be regenerated by the scripts when needed.
